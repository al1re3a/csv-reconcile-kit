# Releasing

1. Run the checks documented in README and review the actual output.
2. Update version metadata and CHANGELOG for future versions.
3. Commit meaningful changes using real timestamps.
4. Tag the reviewed commit and push the branch and tag.
5. Attach source/package artifacts with SHA-256 checksums to the GitHub release.

The initial v0.1.0 release is published to https://github.com/al1re3a/csv-reconcile-kit.
Registry names (PyPI, etc.) have not been reserved or published.
Do not move an already-published release tag; use a new version for later fixes.
